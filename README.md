# GameSphere Connect

Full-Stack Gaming Discovery & Community Platform Prompt

Design and build a modern, premium, production-ready, fully responsive web application called GameSphere. The application must work seamlessly on desktop, tablet, and mobile browsers.

The website is NOT a piracy or game distribution website. It is a gaming discovery, community, and marketplace platform where users can discover games, search and filter them, view detailed information, connect with other gamers, and purchase games through official stores.
